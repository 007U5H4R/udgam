## What was verified clean (with the probe used)

- **Escrow services (`src/lib/agreements`)**: create / fund / refund / grade / settle make the chain call outside any `writeTx`, re-check state inside it, and dedup a lost or concurrent *release* by `(agreementId, txHash)`; `idempotentStep` only resends when the chain already holds the target state; `gradeBatch` verifies the EIP-712 recovery against the org address before anything is anchored; the anchored `settlement` statement carries condition codes and observed values only (EXE29/30). `REASON_BITS` matches `ContractFarming` (1/2/4). `status()` reads struct index 7 = `Status` (checked against the struct layout).
- **`ContractFarming.sol`**: None→Created→Funded→Settled|Refunded; effects before transfers; low-s and v∈{27,28}; `batchReleased` cross-agreement; `settle` after the deadline reverts, `refund` before it reverts; `SettlementRejected` leaves the status Funded. `MockINR` max-allowance convention is correct.
- **EVM adapter (`src/lib/ledger/evm`)**: `coalesced()` single-flight/queue logic (finally runs before the queued continuation, so `running` is cleared before the next `start()`); the frontier query is one statement over `ledger_entries ⟕ evm_anchors`; a `failed` row halts the pass and writes nothing; adopt-if-matches below `nextSeq`; `confirmations` honoured; `errorText` is bounded and carries no key material. Audit counts holes below the chain head only (TASK-25 fix). `verify-anchors` pins chain and contract to the client's.
- **Migrations 0019–0035**: the `user` rebuild drops/recreates the 0009/0016 triggers verbatim (0028/0030); custody trigger ordering (open batch one hop; processor holder hands on to a buyer only); `settlements_consistent` requires a funded agreement and the signed grade; `settlements_one_release_per_batch_idx` (0031) + stricter grade trigger (0032); `agreements_status_flow` requires a released settlement for `funded → settled`, and `settle.ts` inserts the row before the update in the same tx.
- **Processing**: `recordProcessingStep` and `handOnBatch` run entirely inside one `writeTx`; `ratioOf` is integer arithmetic on tenths; `validate.ts` refuses 0 kg; `placeholder-bands.ts` decides "placeholder" from `configVersion`, never by matching the evidence sentence.
- **Harness / release**: `--baseline=v1` refusals (clean tree, READY, no existing baseline, formal options), `regate` re-derives gates from cases, release inputs tied to HEAD by run records and SHA-256, `visibleMarkdown` blanks comments and fences, results/reports never overwritten (`wx` + `-rN`). Clean-room checker: hostile-key guards (`__proto__`, iterative walk), strict base64url, P1363 length, RFC 6962 path check with `sn` exhaustion; `SIGNED_KINDS` = the library's 9.
- **Scripts**: the demo seed refuses outside explicit dev/test or E2E, never prints a password, labels every media row `generated-demo`; key-material files are written 0600; `check-trace.mjs` and `check-bundle-secrets.sh` name variables, never values; `cloud-setup.sh` verifies both tool digests and restores the EXIT trap. Deploy scripts pass the operator key to forge via the child environment only.
- **Helpers**: every e2e seed makes its own org, prints IDs and test-only secrets only, deletes its key file; `tests/helpers/*` write through the real writers.
