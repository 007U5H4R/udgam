## What was checked and found clean (probe in brackets)

- **Guards and org scoping.** Every page, layout, Server Action and the two `(admin)` route handlers call `requireSession(role, …)` first and take `orgId`/`userId` from the session; every org-scoped lookup filters by org in SQL and maps a miss to `notFound()`/404 (`scopedById`, `getOrgBatch`, `getBuyerBatch`, `findRun`, `getReviewDetail`, `getAgreementView`, `getProcessorBatch`, `getAttestation`). The demo page refuses before any read (`demoEnabled` → 404), and `submitStaged` refuses a staging agent outside the admin's org. (Read every `'use server'` file and page; `tests/guard-coverage.test.ts` enforces it.)
- **Sign-in.** Reservation → Better Auth → refund only on non-credential failures; a throttle refusal never reaches Better Auth; only `{status, code}` is logged; success loads the home as a new document (CSP). `refundSignIn` uses `max(count-1, 0)`; `refund` in `rate-limit.ts` is guarded by `count > 0`. (Read; the int tests cover the limits.)
- **Concurrency.** `createBatch`, `overrideRun` and `rerunUnavailable` re-read and re-check inside `writeTx` (membership refusal → `BatchError`, `assertReviewable` again under the lock, run-no race → `not_reviewable`); the remote-sensing re-run happens outside the lock and only the write is serialised. Reads use `db` directly, as EXE3 allows.
- **Proxy / CSP.** Per-request nonce on request and response, redirect responses also carry the policy, `/api`, `.well-known` and the attestation upload are excluded as EXE17/EXE19 say; prefetches skip the proxy and still hit the layout guard.
- **Injection surfaces.** The only `dangerouslySetInnerHTML` uses are the server-made QR SVG and the feed embed, which escapes `<>&` and U+2028/9. The override reason and issuer render in `<bdi>`; URL-derived IDs are `encodeURIComponent`-ed in hrefs and capped in `pageTitle`. `?error=` on the demo page is whitelisted (`failureOf`).
- **Client resource handling.** Object URLs are revoked when previews change; the GPS watch stops on unmount; the Sheet's ResizeObserver and listeners are removed; `ProofPanel` abandons an in-flight verification on unmount; `OfflineSheet` removes its window listeners. `finishAnswered` never rejects (checked `capture-client.ts:323-343`), so the unguarded `void finishAnswered()` calls cannot produce unhandled rejections.
- **Logging.** No email, name, password, cookie, code or key in any `log.*` call in the area (grep); the enrolment code is returned to the admin's page only.
- **Bundles.** The certificate's client chunks do not pull the i18n dictionaries (grep for "verified at origin"/Kannada strings in `.next/static/chunks`); `UDGAM_COMMIT` is the only `env` value inlined.
